# Виктор Велин — БРЕНД и МАЙБАХ

Сайт организатора выступлений Виктора Велина с отдельными страницами кавер-групп БРЕНД и МАЙБАХ. Главная страница — `index.html` в корне репозитория. Сборка и установка зависимостей не нужны.

## Публикация

В GitHub Pages выбрать **Deploy from a branch → main → / (root)**. Адрес сайта: https://dunshaar.github.io/demowebsite/

Страницы, CSS, JavaScript и папка `assets/` должны находиться рядом с `index.html`. Все внутренние ссылки относительные. Исходные материалы, архивы и локальные служебные файлы в репозиторий не входят.

## Страницы

- `index.html` — выбор группы, промо и контакты
- `brend.html` и `mybach.html` — страницы групп
- `brend-repertoire.html` и `mybach-repertoire.html` — полные репертуары без поиска
